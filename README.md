# 🌐 Network Subnet Calculator

A simple and user-friendly Network Subnet Calculator built with Python and Tkinter. This desktop application allows users to calculate essential subnet information by entering an IP address with CIDR notation.

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

- Calculate Network Address
- Calculate Broadcast Address
- Display Subnet Mask
- Display Wildcard Mask
- Show First and Last Usable Host
- Calculate Total and Usable Hosts
- Supports both IPv4 and IPv6
- Simple and modern GUI built with Tkinter
- Input validation with error handling
