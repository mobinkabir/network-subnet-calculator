# 🌐 ماشین حساب شبکه (Network Subnet Calculator)

یک ابزار دسکتاپ ساده و کاربردی که با Python و Tkinter توسعه داده شده است و امکان محاسبه اطلاعات شبکه را تنها با وارد کردن یک آدرس IP به همراه CIDR فراهم می‌کند.

---

## ✨ امکانات

- محاسبه آدرس شبکه (Network Address)
- محاسبه آدرس برادکست (Broadcast Address)
- نمایش Subnet Mask
- نمایش Wildcard Mask
- نمایش اولین و آخرین IP قابل استفاده
- محاسبه تعداد کل آدرس‌ها
- محاسبه تعداد هاست‌های قابل استفاده
- پشتیبانی از IPv4 و IPv6
- رابط کاربری گرافیکی ساده و کاربرپسند
- اعتبارسنجی ورودی و نمایش خطا در صورت وارد کردن IP نامعتبر
